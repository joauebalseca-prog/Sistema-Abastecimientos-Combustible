# Sistema Web para la Gestión de Abastecimientos y Pagos Mensuales de Combustible

Proyecto académico desarrollado para la asignatura de Gestión de Proyectos de Software.

## Descripción
El proyecto propone un sistema web para gestionar clientes, vehículos,
abastecimientos de combustible, pagos y saldos mensuales.

## Innovaciones propuestas
- Módulo de detección de consumos anómalos.
- Automatización de la conciliación mensual de abastecimientos y pagos.

## Estado del proyecto
Actualmente el proyecto se encuentra en etapa de planificación,
documentación y diseño de la solución.
